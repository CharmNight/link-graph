# 功能与限制

## 当前支持的主要能力

### 图分析与展示

- 从当前方法或资源出发生成图数据
- 提供事实图、流程图、资源关系视图
- 支持节点选择、局部编辑、布局更新和视图切换

### Mermaid 相关流程

- 导入 Mermaid
- 导出 Mermaid
- Mermaid 校验与问题展示
- 与当前工作图做差异分析和同步预览

### 源码协同

- 从图节点跳回源码
- 从资源关系结果跳回对应文件
- 面向草稿和设计结果的写回与回退流程

### 工作台、计划、草稿

- 固定工作台 `讲解 / 审计 / 草稿 / 计划 / 代码`
- 步骤化讲解
- 多轮审计会话、候选变更确认与风险线索继续取证
- 草稿层确认
- 实现计划生成
- 代码草稿生成、单条/批量写回与结果回显

## 当前限制

### LLM 相关限制

- 远程 LLM 能力不是默认启用项
- 远程能力需要用户在设置页手动配置
- 远程不可用时，部分流程会回退到本地规则或模板结果
- 因此这些结果不能被理解为完整源码真值或完整自动实现

### 项目类型与主体范围

- 当前主要围绕 Java、Kotlin 和常见资源文件工作
- 实际分析深度仍受 PSI 可见性、索引状态和当前主体范围影响
- 对非常规框架、自定义元编程或动态反射路径的覆盖仍有限

### 前端运行环境

- 前端运行在 JCEF 中，不等同于普通浏览器环境
- 某些浏览器调试体验和独立 Web 应用体验在这里并不完全等价

### 仓库状态

- 仓库仍在持续演进
- 对外文档只说明当前公开结构和当前支持范围
- 不承诺历史设计思路和当前实现完全一致

## 使用建议

- 把图结果视为阅读和定位工具，而不是无条件正确的代码真相
- 对 LLM 生成内容保持审阅意识
- 先确认草稿层，再继续生成计划和代码
