# 功能与限制

## 当前支持的主要能力

### 图分析与展示

- 从当前方法或资源出发生成图数据
- 提供事实图、流程图、资源关系视图、架构图、类图和 Review Graph
- 支持节点选择、局部编辑、布局更新和视图切换
- 架构图和类图基于项目级架构索引投影
- Review Graph 基于代码 diff、工作区变更和架构索引生成变更影响面证据
- 项目级视图会按当前锚点、范围和可读窗口投影，不默认把项目、三方库和 JDK 的全部节点一次性展示
- 架构图默认优先展示项目源码、资源和聚合关系；包依赖视图或显式选项可纳入三方库和 JDK 分组
- 类图支持从当前编辑器类打开，也支持从架构节点下钻

### Mermaid 相关流程

- 导入 Mermaid
- 导出 Mermaid
- Mermaid 校验与问题展示
- 与当前工作图做差异分析和同步预览

### 源码协同

- 从图节点跳回源码
- 从流程图、资源关系视图、架构图、类图和 Review Graph 等投影节点回溯到真实源码锚点
- 编辑器右键支持直接以当前类为锚点打开类图
- 问答取证会收集当前方法源码、类声明和类注解、imports、邻近调用点以及受预算限制的上下游片段
- 从资源关系结果跳回对应文件
- 面向草稿和设计结果的写回与回退流程

### 工作台、草稿

- 顶部任务栏提供 `理解链路 / 核验证据 / 风险问答 / 草稿确认 / 代码落地` 五阶段流程
- 左侧链路大纲、中间图谱舞台、右侧阶段工作台和底部变更托盘共同承载阅读、取证、草稿和代码落地
- 步骤化讲解
- 证据阶段展示选中节点、证据强度、证据缺口、源码片段、风险线程和候选变更
- 多轮问答会话、模式选择、候选变更确认与风险线索继续取证
- 问答请求状态展示请求模式、实际模式、提示词、实际附带源码和取证轨迹
- 提示词查看统一依赖内容或 Artifact ID，不显示不可点击的“可查看”
- 草稿层确认
- 草稿内嵌实现建议生成
- 代码 diff 生成、单条/批量写回与结果回显

## 当前限制

### LLM 相关限制

- 远程 LLM 能力不是默认启用项
- 远程能力需要用户在设置页选择具体预设并完成对应配置
- 远程不可用时，部分流程会回退到本地规则或模板结果
- 问答默认 `Auto`，后端会识别实际模式；显式模式会被优先尊重
- `只回答`、`风险复核`、`代码调整` 和风险线程取证之间有输出边界，普通问答不会自动推进草稿候选
- 因此这些结果不能被理解为完整源码真值或完整自动实现

### 项目类型与主体范围

- 当前主要围绕 Java、Kotlin 和常见资源文件工作
- 实际分析深度仍受 PSI 可见性、索引状态和当前主体范围影响
- 架构图、类图和 Review Graph 依赖项目级架构索引；索引不可用、源码不可见或动态运行时绑定无法静态证明时，关系可能降级为带可信度的弱证据或缺失
- 架构图、类图和 Review Graph 中的节点数量通常表示当前投影候选、后端可见窗口或前端渲染数量，不等同于项目总类数
- 类图无显式范围时优先围绕当前编辑器类生成邻域视图；首次加载可能先显示结构快照，再补齐完整关系
- 三方库和 JDK 依赖不是默认全量铺开；需要通过包依赖视图、显式选项、下钻或后续展开来核对
- Review Graph 的准确性受当前 diff、Git 工作区变更、hunk 到符号映射和相关测试识别能力影响，不能替代完整人工评审
- 源码读取限制在项目根或 IntelliJ Project content root 内；项目外文件不会作为可信证据读取
- 源码上下文收集负责提供材料，不在本地硬编码框架注解语义；触发机制仍需要结合源码、配置、框架回调和人工复核判断
- 对非常规框架、自定义元编程或动态反射路径的覆盖仍有限

### 前端运行环境

- 前端运行在 JCEF 中，不等同于普通浏览器环境
- 某些浏览器调试体验和独立 Web 应用体验在这里并不完全等价

### 仓库状态

- 仓库仍在持续演进
- 对外文档只说明当前公开结构和当前支持范围
- 不承诺历史设计思路和当前实现完全一致

## 使用建议

- 把图结果视为阅读和定位工具，而不是无条件正确的代码真相
- 对 LLM 生成内容保持审阅意识
- 先确认草稿层，再继续生成实现建议和代码 diff
